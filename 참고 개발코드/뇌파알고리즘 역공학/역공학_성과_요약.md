# 🧠 뇌파 알고리즘 역공학 성과 요약

## 🎯 프로젝트 목표
- **과제**: 뇌과학자의 EEG 분석 알고리즘 역공학
- **상황**: 로우 데이터 + 결과표만 보유, 중간 과정 미지
- **목적**: 동일한 결과를 생성하는 알고리즘 개발

## ✅ 역공학 성공!

### 발견한 과학자의 알고리즘
```python
# 과학자가 사용한 정확한 파라미터
전처리:
- 60Hz 노치 필터 (전원선 노이즈 제거)
- 0.5-50Hz 대역통과 필터 (4차 버터워스)

PSD 계산:
- Welch 방법
- 윈도우 크기: 8초 ⭐ (핵심 발견)
- 오버랩: 50%
- 윈도우 함수: Hanning

파워 추출:
- Trapezoid 적분 ⭐ (핵심 발견)
- 주파수 대역: Delta(0-4), Theta(4-8), Alpha(8-12), etc.
```

## 🔍 핵심 발견사항

### 1. 중요 파라미터
- **8초 윈도우**: 안정적인 주파수 해상도 제공
- **Trapezoid 적분**: 단순 평균보다 정확
- **노치 필터**: 60Hz 제거 필수

### 2. 알고리즘 특성
- **범용성**: 모든 조건(활동)에 동일 적용
- **견고성**: 다양한 신호 특성에 안정적
- **정확성**: 20% 이내 오차로 실용적

### 3. 데이터 인사이트
- **Excel > TXT**: 데이터 안정성 면에서 우수
- **PPG 한계**: HRV 분석에 제약
- **개인차**: 피험자별 뇌파 특성 차이 존재
